# راهنمای پروژه Inspection ERP (ICS)

## معرفی پروژه

این پروژه یک سیستم برنامه‌ریزی منابع سازمانی (ERP) تخصصی برای بازرسی فنی و مهندسی است که شامل ماژول‌های TPI، MWS، TPER و بخش‌های سازمانی می‌باشد.

## معماری پروژه

- **الگوی طراحی**: DDD (Domain-Driven Design) + Clean Architecture
- **لایه‌ها**:
  - `app/`: نقطه ورود و تنظیمات اولیه
  - `application/`: موارد استفاده و سرویس‌های برنامه
  - `domain/`: موجودیت‌ها، قوانین کسب‌وکار و رویدادهای دامنه
  - `repositories/`: تعریف اینترفیس‌های مخزن
  - `infrastructure/`: پیاده‌سازی مخازن و ارتباط با زیرساخت

## شروع به کار

### پیش‌نیازها

- Node.js (نسخه 18 یا بالاتر)
- npm یا pnpm

### نصب وابستگی‌ها

```bash
npm install
```

### اجرای سرور توسعه

```bash
npm run dev
```

پس از اجرا، پروژه در آدرس `http://localhost:5173` قابل دسترسی است. تغییرات کد به صورت خودکار بازتاب داده می‌شوند.

### ساخت نسخه تولید

```bash
npm run build
```

### پیش‌نمایش نسخه تولید

```bash
npm run preview
```

## ساختار پوشه‌ها

```
/workspace
├── app/              # نقطه ورود و تنظیمات
├── application/      # منطق کاربرد
├── domain/           # هسته دامنه و قوانین کسب‌وکار
├── repositories/     # اینترفیس‌های مخزن
├── infrastructure/   # پیاده‌سازی زیرساخت
├── public/           # فایل‌های استاتیک
└── package.json      # وابستگی‌ها و اسکریپت‌ها
```

## اصول توسعه

1. **جداسازی ویژگی‌ها**: هر ویژگی باید مستقل و ایزوله باشد.
2. **وابستگی لایه‌ها**: وابستگی فقط از لایه بالاتر به پایین‌تر مجاز است.
3. **الگوی Repository**: دسترسی به داده‌ها فقط از طریق مخازن.
4. **UI واکنش‌گرا**: بهینه‌سازی برای تجربه کاربری سریع.
